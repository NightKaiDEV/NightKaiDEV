👋 About me

Hi, I’m Night Kai, a night-owl developer who is still learning and growing every day. The quiet hours are when I focus best, so most of my code gets written after dark, with a cup of tea and a lot of curiosity. 🌙

I’m not an expert yet, and I’m okay with that. Every bug I fix and every small project I finish makes me a better programmer.

🐍 Python

Python is my main tool for building things quickly. I use it to:

Learn core programming concepts: variables, functions, classes, and modules

Write small scripts that automate boring tasks

Build plugins for exteraGram, a customizable Telegram client

Python is friendly and readable, which makes it great for turning ideas into working projects.

🔌 exteraGram plugins

I enjoy making plugins that add new features and make the messenger more fun and useful. Working on them teaches me:

How to read and understand other people’s code

How to work with APIs and hooks

How to test, debug, and improve my own projects

How to think about the people who will actually use what I make

🧱 Pascal

Pascal is the language I love most, because it’s hard and interesting. Its strict structure forces me to think carefully about types, logic, and how a program is organized. It’s not always easy, but that’s what makes it rewarding. Pascal taught me discipline, and it made me a better programmer in every other language I use.

🎯 What I’m working on

Getting stronger in Python and Pascal

Building and improving exteraGram plugins

Learning clean code habits and better project structure

Exploring new ideas, one small project at a time

🌱 My philosophy

Hard things are worth learning. Every error is a lesson. Keep building, even at 3 AM.

📫 Let’s connect

I’m always happy to meet other learners, share ideas, get feedback, or help with plugins. If you like Python, Pascal, or Telegram mods, say hi!

Night Kai 🌙: coding under the moonlight.

* 🌍  I'm based in New York
* 🧠  I'm currently learning Rust
